## Context

- G6: hostile input gives SyntaxError or RangeError, never an abort. JS recursion must throw a RangeError, so every interpreter and JIT prologue, every recursive Rust builtin and the parser need a stack check [R09].
- D14: termination comes from another thread. [R18]: an inspector session can run JS at any interrupt poll, so polls are also lazy-deopt points (H24, H29).
- Depends on: H14 (frames), H15 (dispatch), H28 (platform mechanism). Depended on by: H24 (debugger polls), H29 (deopt at polls), H32.

## Decision

Limit checks on VM and native stacks: calls, JIT and AOT prologues, recursive builtins, the 3-layer depth guard. Interrupt polls shared with safepoints and tier-up. Embedder interrupt callbacks never run JS; only an inspector session runs JS at a poll. Heap limit + callback. `panic = "abort"` in release; never unwind panics through JIT or AOT frames (02 §6).

## Consequences

- **Gains.** Hostile input gives catchable errors (G6). ep9 recurses 10x deeper than node, so recursion that works on node works on ep9. Termination needs no signal.
- **Costs.** Since the switch (M0 month 2 P2), a panic in a release build ends the process: a test262 panic is a `worker crash` with the panic text from the worker's stderr (crash isolation per file, M2-P1-ABORT-PRE), and `ep9` exits 70 through its panic hook. An abort on Windows exits with 0xC0000409. No default heap limit below the cage (H23-Q3): a runaway script uses up to the 64 GiB cage unless the embedder sets `max_heap_bytes`. An interrupt callback waits for the next poll: up to one budget (10,000 back edges, bytecode calls or other budget units) while JS runs, and until the next run when the isolate is idle. A call of a host function that is not bound takes no budget unit, so code that only calls such functions does not poll: for example, straight-line code of host calls, or an embedder loop of `Isolate::call` on a host function. The callback and a termination then wait for the next bytecode call, back edge, bound-function level or builtin poll. A call of a bound function takes one unit per bound level, also when its target is a host function (Facts, Interrupt poll).
- **Follow-ups.** H28-Q3 handler; each recursive builtin calls `Cx::check_native_stack` (`crates/ep9_vm/src/abi/index.rs:94`) at each recursion step when it lands (from week 4; the first is FlattenIntoArray, M0 month 2 P4). Done: the near-limit callback and the embedder interrupt callback (M0 month 2 P3), prologue checks (Spike B, H23-Q5).
