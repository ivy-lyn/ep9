## Harness

`node tools/bench/cross/v8v7.mjs --kernel richards --harness base` writes the real pinned
`base.js`, unchanged, as its own strict script (indirect eval), then the kernel, then base.js's
`BenchmarkSuite.RunSuites`. Only `RunSingleBenchmark` changes: `run()` N times, timed with `Date`
(not "for 1 s": class M compares wall time per process). The output is the stub's, so run.mjs
checks it the same way. The JSON names the harness per workload.

Status at the PERF3 head (`v8v7.mjs --blockers target/release/ep9 --harness base`):

| Kernel | node 24 | ep9 (PERF3 head) | Cause |
|---|---|---|---|
| richards | `Richards 200` | prints `Richards 200`, then `TypeError: undefined is not a function` at base.js:152 | `GeometricMean` calls `Math.log` |
| deltablue | `DeltaBlue 100` | same error after `DeltaBlue 100` | same |

base.js after the timed loop needs `Math.log`, `Math.pow` (ep9 has it) and
`Number.prototype.toFixed` (base.js:162). ep9 has no `Math.log` and no `toFixed` at this head
(`ep9 -e 'print(typeof Math.log, typeof Number.prototype.toFixed)'` prints `undefined
undefined`). No M3 phase owns them. Until they land, run 3 uses `--harness stub`; the timed part
(the kernel's `run()`) is the same code in both harnesses.

## IC counters (ic-stats)

`--features ep9_vm/ic-stats` counts each named and global IC access at the T0 handlers
(`ic.rs` `stats`). A hit is the inline fast path. A miss goes to the slow path; the counter
records the state of the slot then (no vector, uninitialized, mono, poly, mega). PERF3 head,
macOS arm64, `EP9_HASH_SEED=1`, stub harness:

| richards | store | 10,133,669 | 3,766 | 3,698 | 68 | 0 | 0 | 0 |
| richards | load-global | 8,262,537 | 507 | 465 | 42 | 0 | 0 | 0 |
| richards | store-global | 0 | 21 | 21 | 0 | 0 | 0 | 0 |
| deltablue | load | 33,405,305 | 23,768 | 23,129 | 362 | 57 | 220 | 0 |

| ci-v0 | store | 0 | 10,000 | 10,000 | 0 | 0 | 0 | 0 |
| ci-v0 | load-global | 21,882 | 16 | 15 | 1 | 0 | 0 | 0 |
| ci-v0 | store-global | (no access) | | | | | | |

Reading: on richards and deltablue the named-load hit rate is above 99.9 %; most misses are "no
vector" (code that has no feedback vector yet: a function before its 8th call, and top-level
code). ci-v0 does most of its work at top level, so its stores all miss. On deltablue,
load-global misses (6,907) are mostly no-vector too. The binary prints one line per site kind to
stderr at exit: `ep9 ic-stats: <site> hit=N miss=N (no-vector=.. uninit=.. mono=.. poly=..
mega=..)`.
